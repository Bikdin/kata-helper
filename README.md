# KATA Helper 0.1 — боковая панель

Группировка алертов KATA: технология (`type`) → объект (`details.object`) → количество,
по клику на объект — Source и Destination IP с кнопками «Копировать».

## Как работает

- Окно открывается в боковой панели Edge, на страницу KATA ничего не добавляется.
- Данные запрашиваются только по кнопке «Обновить»: расширение на мгновение запускает
  на вкладке KATA короткий скрипт в изолированном окружении, он делает тот же запрос
  `POST /apt/api/pcn/allAlerts`, что и интерфейс KATA (от вашей сессии), и возвращает ответ в панель.
- Доступ запрашивается только к адресу KATA, который вы указали. Других запросов нет.
- Хранится только адрес KATA и company_id (`chrome.storage.local`, без синхронизации).
- Сервер KATA видит эти запросы как обычные запросы вашей учётной записи.

## Установка

1. `edge://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка `kata-helper`.
2. Закрепить значок (иконка пазла → глаз).
3. Клик по значку → откроется боковая панель → ⚙ → адрес KATA → «Сохранить» → разрешить доступ.
4. Если KATA ответит «No permissions to company or node» — вставить company_id из
   F12 → Network → allAlerts → Payload в ⚙ и сохранить.

## Использование

Откройте KATA (вкладка должна быть открыта и вход выполнен) → значок расширения → «Обновить».

Статусы алертов (`new`, `rescan`) и путь запроса заданы в начале `sidepanel.js`.
